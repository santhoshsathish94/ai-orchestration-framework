# Templates

> **Direction → Context → Action → Success → Growth**

Reusable artifacts for running work through the cycle. Copy a template, rename it for the task, and
fill it in as the work proceeds. The value is in clear direction, real context, and honest evidence,
not in length.

## Available templates

- **[Orchestration Brief](orchestration-brief.md)** — a one-page brief covering all five leaves,
  with copy-and-paste AI prompts and explicit human and AI ownership at each leaf.

See it applied end to end in
[`examples/production-exception-remediation/`](../examples/production-exception-remediation/), or start
with the [Quickstart](../QUICKSTART.md).
